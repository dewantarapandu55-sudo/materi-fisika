📘 KELAS 10 LENGKAP

1. Besaran: Pokok = Panjang(m), Massa(kg), Waktu(s), Suhu(K), Arus(A). Turunan = Kecepatan, Gaya, Energi.

2. Vektor: Punya besar + arah. Contoh: Gaya, Kecepatan.

3. Gerak Parabola: Bola ditendang. Gabungan GLB + GLBB. Jarak terjauh sudut 45°.

4. Gerak Melingkar: v = ω x r, a = v2 / r

5. Hukum Newton: 1. Diam tetap diam. 2. F = m x a. 3. Aksi = Reaksi.

6. Usaha & Daya: W = F x s, P = W / t

7. Momentum: p = m x v, I = F x Δt. Momentum kekal saat tumbukan!

8. Suhu & Kalor: Q = m x c x ΔT. Azas Black: Q lepas = Q terima.

📙 KELAS 11 LENGKAP

1. Torsi: τ = F x r. Bikin benda muter.

2. Kesetimbangan: ΣF = 0 dan Στ = 0. Contoh: Jungkat-jungkit.

3. Elastisitas: F = k x Δx. EP Pegas = 1/2 k Δx2

4. Fluida: Pascal: F1/A1 = F2/A2. Archimedes: Fa = ρ g V

5. Fluida Dinamis: Q = A x v. Bernoulli: Pesawat bisa terbang!

6. Termodinamika: Q = ΔU + W. Mesin Carnot: η = 1 - T2/T1

7. Gas: P x V = n x R x T

8. Bunyi: Doppler, Resonansi. v bunyi = 340 m/s

📗 KELAS 12 LENGKAP

1. Listrik Statis: F = k q1 q2 / r2. E = k q / r2

2. Listrik Dinamis: R seri = R1+R2. 1/R paralel = 1/R1+1/R2. P = V x I

3. Magnet: F Lorentz = B x I x L. F = B x q x v

4. Induksi: ε = -N ΔΦ / Δt. Generator!

5. Gelombang Elektromagnetik: Radio, Mikro, Inframerah, Cahaya, UV, X, Gamma

6. Optik: 1/f = 1/s + 1/s'. M = s'/s

7. Alat Optik: Mata, Lup, Mikroskop, Teropong

8. Fisika Modern: E = m c2. E foton = h x f

9. Inti: Fisi = belah (PLTN), Fusi = gabung (Matahari). N = N0 (1/2)^(t/T)
